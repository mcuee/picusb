The schematic of the development board included with the CY3684 kit is same as CY3674 EZ-USB FX1
development board schematic. The only difference is replacing U1 component on board 
FX2LP IC CY7C68013A-128AXC with EZ-USB FX1 IC  CY7C64713-128AXC .

The SRAM part CY7C1019BV33-12VC and CY7C1019DV33-10VXI  are pin-to-pin compatible.
The existing schematic files-.DSN .PDF and PCB layout files - xx.brd ,Gerber.zip ..etc
can be used for new SRAM part CY7C1019DV33-10VXI.
